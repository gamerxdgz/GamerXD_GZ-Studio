# GamerXD_GZ Code Studio

GamerXD_GZ Code Studio is a free, browser-based coding workspace designed to let users create small web projects directly in their browser.

The project is designed to be simple, lightweight, and privacy-friendly without requiring an account.

## Features

- Browser-based code editor
- Create and edit multiple files
- No account required
- Work is kept in the browser during the session
- Automatic local saving to help prevent accidental data loss
- Download project files
- Download the complete project
- Create HTML, CSS, JavaScript, and other text-based files
- Simple project management
- Runs directly in the browser
- Designed to work on desktop, tablet, and mobile devices
- Free to use

## File Limits

To keep the editor lightweight and reliable, projects have limits.

### Maximum files

A project can contain up to:

**20 files**

### Maximum lines per file

Each file can contain up to:

**5,000 lines**

These limits may be changed in future versions.

## Accounts

GamerXD_GZ Code Studio does not require user accounts.

Users can start coding immediately without creating an account or providing personal information.

Because there are no accounts, projects are stored locally in the user's browser rather than being associated with an online account.

## Saving

The editor uses browser storage to preserve work.

This is intended to help protect projects from accidental refreshes or navigation away from the page.

However, browser storage should not be considered a permanent backup.

Users should download their projects regularly if the project is important.

Clearing browser data, using private/incognito browsing, changing browsers, or certain browser settings may remove locally stored projects.

## Downloading Projects

Users can download their code and project files from the editor.

Downloaded projects can be saved to the user's computer and opened or edited later.

The exact download format may change as the project develops.

## Privacy

GamerXD_GZ Code Studio is designed to avoid requiring an account.

The project does not require users to submit personal information simply to use the editor.

Projects are intended to remain locally stored in the user's browser unless a future feature specifically states otherwise.

## Security

The project is designed with security and reliability in mind.

However, no website or software can guarantee perfect security.

Users should avoid placing passwords, API keys, tokens, private credentials, or other sensitive information into browser-based projects.

## Technology

The project is built using standard web technologies, including:

- HTML
- CSS
- JavaScript
- Browser APIs

The project is designed to run without requiring users to install additional software.

## Compatibility

GamerXD_GZ Code Studio is intended to work with modern browsers such as:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Safari

Some features may behave differently depending on the browser.
